Review Bootstrap Policy Behavior

This YAML creates a secure baseline, not a finished access policy.

The playbook builds a basic firewall configuration and intentionally blocks unmatched interzone traffic.

  • Traffic between zones will not be permitted until explicit security policy allow rules are added.
  • Default block rules include known-bad IP lists, high-risk geo destinations, and unsanctioned applications.
  • Review, order, and tune security policy after bootstrap for the site-specific applications and zones.
